# three-js-sandbox — 浸水シミュレータ（KAIYO MARU）

全長 30 m の小型貨物船が被雷・破口から浸水し、区画ごとに水が広がって沈んでいく様子を 3D で観察するシミュレータ。
船内の水は **GPU 上の粒子法（MLS-MPM）** で解いており、扉・ハッチ・階段・機関室ケーシングを通って実際に流れる。

## 動かし方

- Node.js 20 以上
- **WebGPU 対応ブラウザ**（Chrome / Edge 113 以降）。独立 GPU 推奨（RTX 3080 で「標準」画質 60 fps を想定）

```bash
npm install
npm start   # http://localhost:5173
npm test    # CPU 側（船型・区画格子・水位と流量・波・船体運動）のテスト
```

画質は画面左の「表示 → 画質」で切り替える（軽量 13 万粒子 / 標準 26 万 / 高精細 39 万）。

- **表示**: 外観 / **透視**（カメラの側の外板・甲板・壁だけを透かし、船内を立体のまま見る。回り込むと透かす面が変わる）/ 断面（中心線で縦に切った側面図）。透視・断面では「甲板を外す」で上から部屋に入れる
- **カメラ**: ドラッグで回転・右ドラッグで平行移動・ホイールでズーム、**W A S D** で前後左右・**Q E** で下降と上昇・**Shift** で速く
- **空気圧**: 環境タブで破断の有効・無効と構造の強さを変えられる。水密扉タブで通風筒やハッチを閉じると、閉じ込められた空気の振る舞いと破断を見られる
GPU が失われた場合は自動で止まり、次回は「軽量」で起動する。

## 物理モデル

| 対象 | 方法 |
| --- | --- |
| 船体の運動 | Rapier の剛体。船体を 0.5 m のセルに分け、波の中の浮力・線形減衰・形状抵抗を合力とトルクにして加える |
| 波 | ガーストナー波 12 成分（PM 型スペクトルで有義波高に正規化）。浮力（CPU）と海面の描画（GPU）で同じ成分を使う |
| 船内の水 | 船体座標に固定した格子（h = 0.25〜0.36 m）上の MLS-MPM。弱圧縮性（線形の状態方程式、水深 5 m で 12% 縮む剛性）。船の傾き・並進加速度・回転（遠心力・オイラー力・コリオリ力）を見かけの力として入れる |
| 流入 | 開口部ごとに、海面下の深さと部屋の水位の差からオリフィス式 Q = Cd·A·√(2gΔh) で流量を求め、その分の粒子を噴流の速さで生成する。海面より上の開口からは水がこぼれ出る |
| 連成 | GPU で水の質量・重心・慣性テンソルを集計し、船体と合成して剛体の質量特性にする（付加重量法。自由表面の揺れによる重心移動も反映） |
| 区画 | 水密隔壁 4 枚・5 水密区画 + 甲板室。水密扉 3 枚・船外の開口 8 か所（ハッチ・扉・通風筒）は開閉できる。隔壁・甲板は格子の 1 層として厳密に水密（テストで保証） |
| 空気 | 部屋ごとの空気量（等温・ボイルの法則）。扉の上端が水面より上ならその部屋どうしは同じ圧力。閉じ込められた空気は水に押されて縮み、流入を押し返す（エアクッション）。開口の水面より上の部分から空気が出入りし、水中なら外の水圧を超えた分だけ泡で抜ける。GPU 流体には部屋の境目の圧力の段差として入れる |
| 破断 | 外板の点ごとに（空気圧 + 中の水圧）− 外の水圧 を強度（外板 0.3 MPa・上甲板 0.15 MPa・甲板室の壁 60 kPa・閉じた開口 50 kPa、±15%）と比べ、0.3 s 続けて超えたら破る。閉じた開口は蓋が外れて開き、それ以外は 0.8 m の穴になる。外向き（中の空気が破裂させる）と内向き（沈んだ密閉区画が圧潰する）の両方 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/hull.js` | 船体形状の SSOT（物理・格子・描画が共通で参照） |
| `src/layout.js` | 船内配置の SSOT（隔壁・甲板・部屋・扉・ハッチ・機器・船外開口） |
| `src/voxel.js` / `src/shipgrid.js` | 流体格子の分類・距離場・滑り境界、破口の部屋ごとの分割 |
| `src/flooding.js` | 部屋の水位と開口部の流量 |
| `src/air.js` | 船内の空気（圧力・部屋のつながり・空気の出入り・外板の荷重と強度） |
| `src/cameraKeys.js` | W A S D でのカメラ移動量 |
| `src/waves.js` | 波の成分と海面高さ |
| `src/sim.js` / `src/massprops.js` | 船体の運動と質量特性の合成 |
| `src/gpu/fluid.js` | GPU 流体（WebGPU compute / three.js TSL） |
| `src/render/` | 舞台・船の 3D モデル・海面・流体の描画（スクリーンスペース流体）・効果 |
| `src/ui/` / `index.html` / `styles.css` | 区画図・チャート・操作パネル |
| `dev/` | 開発用ページ（流体単体の性能確認、流体なしの船モデル確認） |

## テストの範囲

`npm test` は node 上で動く部分（船型・区画の水密性・扉の開閉による連結・破口の分割・距離場・水位と流量・空気圧とエアクッションの釣り合い・外板の荷重・波・船体の浮き方と沈み方・カメラ移動）を検証する。
GPU 流体は `dev/fluid-selftest`（ブラウザ）で、静水・水密・扉・空気圧の段差・流入を確かめる。
GPU 流体と描画は node で動かせないため、ブラウザで `window.__app.advance(n)`（描画を待たずに n フレーム進める）を使って確認する。
